## 2. Kontrakt
ADR-000 §6 „CLI `map-qa compare-counts`”, §7 (zmienne — tylko obecność, nigdy wartości), D-02 (`POST {host}/api/2.0/sql/statements/`, `wait_timeout` "30s", `disposition` "INLINE", `format` "JSON_ARRAY", `urllib` z biblioteki standardowej). PRD AC-05.

API:
- `TABLES = ["osm_roads", "overture_segments", "photos", "photo_road_links", "traffic_signs"]` (schemat `workspace.map_qa`).
- `REQUIRED_VARS = ("DATABRICKS_HOST", "DATABRICKS_TOKEN", "DATABRICKS_SQL_WAREHOUSE_ID")`.
- `build_statement() -> str` — jedno zapytanie `SELECT '<t>' AS source, count(*) AS rows FROM workspace.map_qa.<t> UNION ALL ...` dla 5 tabel w tej kolejności.
- `build_request(env: Mapping[str,str]) -> urllib.request.Request` — URL `https://<host bez schematu i końcowego />/api/2.0/sql/statements/` (host może mieć `https://` lub nie), metoda POST, nagłówki `Authorization: Bearer <token>`, `Content-Type: application/json`, ciało JSON `{warehouse_id, statement, wait_timeout:"30s", disposition:"INLINE", format:"JSON_ARRAY"}`.
- `@dataclass class RemoteCounts: status: str  # "ok" | "unavailable"; reason: str; remote: dict[str, int]`.
- `fetch_counts(env=os.environ, transport=None, parser=None) -> RemoteCounts`:
  - brak którejkolwiek zmiennej → `unavailable`, `reason` = `"brak zmiennych środowiskowych: <NAZWY>"` (tylko nazwy);
  - `transport` (domyślnie `lambda req: urllib.request.urlopen(req, timeout=40).read()`) rzuca `urllib.error.HTTPError` → `reason="błąd HTTP <kod>"`; `URLError`/`TimeoutError`/`OSError` → `reason="błąd połączenia: <klasa wyjątku>"`; nigdy nie przepuszcza wyjątku;
  - sukces: `parser(body_bytes) -> dict[str,int]` (domyślnie `parse_response`); wyjątek parsera → `unavailable`, `reason="nieoczekiwany kształt odpowiedzi"`.
  - **Wartość tokenu nigdy nie trafia do `reason`, logów ani wyjątku** (test: ustaw `DATABRICKS_TOKEN="test-token-xyz"` i sprawdź `reason`/`repr`).
- `parse_response(body: bytes) -> dict[str,int]` — zaimplementuj według dokumentacji Statement Execution API (`result.data_array`, `status.state == "SUCCEEDED"`), **ale test parsowania oznacz `pytest.mark.skip(reason="brak capture")`** — nie wymyślaj kształtu odpowiedzi w teście (AGENTS.md: mock tylko z capture). Orkiestrator doda capture w T4.5.
- `compare(local: dict[str,int], remote: RemoteCounts) -> list[dict]` — wiersze `{table, local, remote, match}` (remote/match = None gdy unavailable).

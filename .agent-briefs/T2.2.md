## 2. Kontrakt
ADR-001 §4.1–4.4 (`docs/ADR/001-dane-normalizacja-dopasowanie.md`), D-102. Moduł czysty: nie importuje niczego z pakietu `map_qa`, bez I/O.

API (dokładnie te nazwy):
- `@dataclass(frozen=True) class Normalized: status: str  # "value" | "missing" | "not_comparable"; value: int | str | None; detail: str; raw: str` + właściwość `comparable -> bool` (`status == "value"`).
- `detail` dla prędkości: `numeric`, `other_unit`, `multiple`, `implicit`, `special`, `missing`, `directional`, `conditional`; dla nawierzchni/lit: `paved_unpaved`/`lit` przy wartości, `unknown_value`, `partial` (reguła z `between` lub > 1 reguła), `missing`.
- `parse_maxspeed_value(s: str | None) -> Normalized` (raw = surowy tekst lub `""`). Spacje z brzegów usunięte; jednostka `km/h` bez względu na wielkość liter i spację; `mph`, `knots` → `other_unit`; `;` → `multiple`; wzorzec `^[A-Z]{2}:` → `implicit`; inne → `special`; puste/None → `missing`. Nigdy nie rzuca.
- `parse_osm_speed(tags: dict) -> Normalized`: `raw = to_json({k: v for k, v in tags.items() if k.startswith("maxspeed")})` (kolejność kluczy jak w wejściu). Reguły kolejno: `maxspeed:conditional` → `not_comparable/conditional`; tagi kierunkowe (`maxspeed:forward`/`:backward`): wartość każdego kierunku = jego tag albo ogólne `maxspeed`; brak którejkolwiek → `directional`; obie liczbowe i równe → wartość; inaczej `directional`; bez tagów kierunkowych → `parse_maxspeed_value(tags.get("maxspeed"))` (z `raw` całego zestawu `maxspeed*`). `maxspeed:type`, `:hgv`, `:bus`, `:trailer` ignorowane przy porównaniu, ale są w `raw`.
- `@dataclass(frozen=True) class SpeedRule: max_kmh: int | None; unit: str | None; has_when: bool; between: list | None; is_variable: bool`.
- `speed_rules(rules) -> list[SpeedRule]`.
- `parse_overture_speed(rules: list | None) -> Normalized`: `raw = to_json(rules)` (dla None: `"null"`); None/[] → `missing`; porównywalne tylko: dokładnie 1 reguła, `max_speed.unit == "km/h"`, `when` puste, `between` puste, `is_max_speed_variable` nie True → `value`=`max_speed.value` (int); jednostka inna → `other_unit`; inaczej `not_comparable` z `detail` `partial`/`conditional`/`multiple`.
- `parse_osm_surface(value, paved, unpaved) -> Normalized`: strip, dopasowanie dokładne z rozróżnieniem wielkości liter; raw = wartość po strip? **Nie** — raw = surowa wartość bez zmian (`""` dla None).
- `parse_overture_surface(rules, paved, unpaved) -> Normalized`: raw = `to_json(rules)`; None/[] → `missing`; dokładnie 1 reguła bez `between` → mapowanie (inne wartości, np. `unknown` → `not_comparable/unknown_value`); inaczej `not_comparable/partial`.
- `parse_lit(value) -> Normalized`: `yes`, `automatic`, `24/7` → `yes`; `no` → `no`; puste/None → `missing`; inne → `not_comparable`.
- `to_json(obj) -> str`: `json.dumps(..., ensure_ascii=False)` z domyślnymi separatorami, konwersja numpy (`ndarray` → list, `np.integer` → int, `np.floating` → float, NaN → None), rekurencyjnie w dict/list.

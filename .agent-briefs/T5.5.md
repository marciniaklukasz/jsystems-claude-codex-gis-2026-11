# T5.5 — `evaluation`: trafność i pokrycie odczytu (TDD)

## 1. Cel
Moduł `app/src/map_qa/evaluation.py` i testy `app/tests/unit/test_evaluation.py`: najpierw testy (Red — pokaż powód porażki w raporcie), potem kod (Green). Bez sieci.

## 2. Kontrakt
ADR-002 §4.7 (źródła etykiet), §4.10, §8 wiersz „Ewaluacja”; PRD AC-23, AC-20e. Moduł zależy tylko od `config` (nie importuj `vision`, `compare`).

API:
- `load_labels(data_dir) -> DataFrame` z kolumnami `photo_id, question_id, label, status, sequence, image_path, author, license, source_url`:
  - prędkość (`question_id="speed_limit_value"`) **wyłącznie** z `signs/labels.csv` (`sign_value` → `label`; `status`), `sequence`, `creator` → `author`, `license`, `source_url` z `signs/signs.csv` (po `photo_id`); `image_path = data_dir/"signs"/"photos"/f"{photo_id}.jpg"` jeśli plik istnieje, inaczej `None`. Wiersze `speed_limit_value` z `reference_labels.csv` są pomijane (ADR-002 §4.7: prędkość z `signs/labels.csv`).
  - pozostałe pytania (`surface`, `junction_visible`, `street_lighting_visible`) z `reference_labels.csv` (`question` → `question_id`, `label`, `status`); `sequence`, `author`, `license`, `source_url`, `filename` z `photos.csv`; `image_path` = `data_dir/"offline"/filename` albo `data_dir/"data"/"photos"/filename` (pierwszy istniejący), inaczej `None`.
  - CSV czytaj jako UTF-8, `dtype=str`, puste → `""`; `image_path` jako `str` albo `None`.
- `evaluate(readings, labels, comparison=None) -> dict` — wynik per pytanie:
  `{qid: {"pairs": int, "uncertain_labels_excluded": int, "rows": [ {"split", "who", "pairs", "certain", "correct", "coverage", "accuracy"} ]}}`
  - `readings` kolumny: `photo_id, question_id, split, decision_answer, decision_confident, answer, status` (patrz `vision` ADR-002 §4.3; `status == "certain"` = pewny odczyt po eskalacji).
  - Tylko pary z etykietą `certain` dla danego pytania (join po `photo_id`,`question_id`); `uncertain_labels_excluded` = liczba etykiet `uncertain` dla pytania w całym `labels`.
  - `who`: `"decision"` (pewne = `decision_confident` True; poprawne = `decision_answer == label`), `"after_escalation"` (pewne = `status == "certain"`; poprawne = `answer == label`), `"comparison"` (z `comparison`: kolumny `photo_id, question_id, split, answer, confident`; tylko gdy podano i niepuste).
  - Wiersze dla każdego `split` obecnego w danych oraz `"all"`. `coverage = certain / pairs` (0 par → `None`); `accuracy = correct / certain`, a przy `certain == 0` → `None` („brak danych”, nie 0). Zaokrąglenie do 3 miejsc.
  - Porównanie etykiet jako tekst po `strip()` (`"50"` == `"50"`).
- `thresholds_met(result, th) -> dict[qid, bool|None]` — `coverage` i `accuracy` wiersza `who="after_escalation"`, `split="all"` względem `th["evaluation"]["min_coverage"]`, `min_accuracy`; brak danych → `None`.

## 7. Dane testowe (wymagane przypadki)
- ADR-002 §8: 4 pary, 3 pewne, 2 poprawne → `coverage` 0.75, `accuracy` 0.667; 0 pewnych → `accuracy` None.
- Etykieta `uncertain` nie wchodzi do par i jest liczona w `uncertain_labels_excluded`.
- `load_labels` na prawdziwych danych (`tests/conftest.py` fixture `data_dir`): 115 wierszy `certain` dla `speed_limit_value`; `surface` certain = 99 (ADR-000 §5.1); każdy wiersz prędkości ma istniejący `image_path`; brak wierszy prędkości z `reference_labels.csv`.

## 1. Cel
Odpowiedzi ze źródłami (ścieżka pliku + numer linii w zainstalowanym SDK) na pytania z ADR-002 §2 „Do potwierdzenia przed kodem” i ADR-000 D-03. SDK jest zainstalowany w `app/.venv/Lib/site-packages/openrouter/` — czytaj **kod źródłowy**, nie zgaduj. Opcjonalnie Context7 (`/openrouterteam/python-sdk`), jeśli masz dostęp; inaczej tylko kod.

## 2. Pytania
1. Nazwy argumentów konstruktora klienta (`OpenRouter(...)`): klucz API, `server_url`, `retry_config`, `timeout_ms`, klient HTTP. Jaki jest domyślny `server_url` (host)?
2. Jak wyłączyć retry: klasa `RetryConfig` / `BackoffStrategy`, strategia `"none"`; czy da się podać per wywołanie (`retries=`)? Jakie są domyślne retry?
3. `alpha.decisions.create(...)` (lub odpowiednik): pełna sygnatura — `model`, `state`, `questions`, `provider`, `retries`, `server_url`, `timeout_ms`, `http_headers`. Czy `timeout_ms` jest obsługiwany per wywołanie?
4. Kształt `state` (części tekst/obraz: nazwy pól, typ `image_url`), `questions` (pytanie `choice`: pola `type`, `prompt`/`question`, `criteria`/`options`?), `provider` (`allow_fallbacks`). Podaj typy modeli Pydantic z pliku.
5. Kształt odpowiedzi `DecisionsResponse`: `answers[question_id]` (pola `choice`, `probabilities`, `confidence`), `usage` (`input_tokens`, `output_tokens`, `cost`).
6. `chat.send(...)`: argumenty `model`, `messages` (część obrazu `image_url` z data URL), `reasoning` (`effort`), `response_format` (`json_schema`, `strict`), `max_tokens`/`max_completion_tokens`, `provider.require_parameters` — gdzie leży; `stream` domyślnie? Czy odpowiedź ma `usage.cost`?
7. Czy SDK udostępnia nagłówki odpowiedzi HTTP (np. `raw_response`, `http_meta`, hooks)? Jak?
8. Klasy błędów (per status HTTP, timeout, błąd połączenia) — nazwy i moduł.
9. Czy istnieje sposób podstawienia transportu (np. `client=httpx.Client(transport=...)`), który pozwala w testach podać odpowiedź bez sieci?

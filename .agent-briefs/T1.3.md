### `src/map_qa/config.py`
- `APP_DIR = Path(__file__).resolve().parents[2]`, `REPO_ROOT = APP_DIR.parent`.
- `DEFAULT_DATA_DIR = REPO_ROOT/"course-materials/exercise-data/map-qa"`, `DEFAULT_OUT_DIR = REPO_ROOT/"reports/map-qa/runs"`, `DEFAULT_DB = DEFAULT_DATA_DIR/"data/map_qa.db"`, `THRESHOLDS_PATH = APP_DIR/"config/thresholds.toml"`.
- `resolve_repo_path(p: str|Path) -> Path`: absolutna bez zmian; względna → względem `REPO_ROOT` (P7).
- `load_thresholds(path=THRESHOLDS_PATH) -> dict` (`tomllib`).
- `MAX_LIMITS = {"decision": 25, "comparison": 5, "fallback": 10}`.
- `@dataclass(frozen=True) class Limits: decision:int=0; comparison:int=0; fallback:int=0; max_cost_usd:float=0.0` + `def any_positive(self) -> bool`.
- `class ArgumentValidationError(ValueError)` (komunikat po polsku).
- `validate_limits(limits: Limits) -> None`: limit < 0 lub > maks. → błąd; dowolny limit > 0 przy `max_cost_usd == 0` → błąd; `max_cost_usd < 0` → błąd.

### `src/map_qa/ingest.py`
- `class InputIntegrityError(Exception)` z atrybutem `.filename` (sama nazwa pliku) i komunikatem po polsku zawierającym nazwę pliku.
- `load_sources(data_dir) -> dict` (`sources.json`, **UTF-8**).
- `verify_inputs(data_dir) -> list[dict]` — dla każdego pliku z `sources.json["files"]`: brak pliku albo inny rozmiar albo inny SHA-256 → `InputIntegrityError(nazwa)`. Wynik: `[{"name","bytes","sha256"}]`. Hash strumieniowo (bloki 1 MiB).
- `@dataclass class Layers: osm: GeoDataFrame; overture: GeoDataFrame; photos: DataFrame; links: DataFrame; traffic_signs_count: int; sources: dict`.
- `load_layers(data_dir) -> Layers`:
  - OSM: `geopandas.read_parquet`, potem `set_crs(sources["osm"]["crs"], allow_override=True)`; kolumna `tags_raw` = surowy tekst JSON z kolumny `tags` (bez zmian), `tags_dict` = `json.loads`.
  - Overture: `read_parquet`, `set_crs(sources["overture"]["crs"], allow_override=True)`.
  - `photos.csv`: `pandas.read_csv(..., encoding="utf-8")`; `heading` jako float (pusty → NaN, `0.0` zostaje 0.0); `photo_id` jako str.
  - `photo_road_links.csv`: `osm_way_id` jako nullable `Int64`, `overture_id`/`candidate_flags`/`match_method` jako str z pustymi → `""`.
  - `traffic_signs.geojson`: tylko liczba obiektów (`len(json["features"])`).
  - Brak wymaganej kolumny → `ValueError` z nazwą kolumny.

### `src/map_qa/cli.py`
- `main(argv: list[str] | None = None) -> int` (zwraca kod; NIE woła `sys.exit`), plus `def entrypoint(): sys.exit(main())` — zmień w `pyproject.toml`? **NIE** — `pyproject.toml` jest hotspotem orkiestratora; wpis `map-qa = "map_qa.cli:main"` już istnieje, więc `main()` przy wywołaniu z entry pointu musi zwracać int (setuptools/uv entry point robi `sys.exit(main())`).
- `argparse`, podkomendy `check` i `compare-counts` (ta druga na razie: wypisz „Ograniczenia: Databricks — nie zaimplementowane w T1.3” i zwróć 0; podłączy ją orkiestrator w T4.5).
- `check`: `--stage {1,2}` (wymagane), `--decision-limit`, `--comparison-limit`, `--fallback-limit` (int, domyślnie 0), `--max-cost-usd` (float, domyślnie 0), `--out`, `--data-dir`, `--db` (domyślne z `config`, rozwiązywane `resolve_repo_path`).
- Błędy argparse muszą dać kod 2 (złap `SystemExit` z argparse i zwróć 2; komunikat po polsku na stderr). Walidacja limitów → kod 2 **przed** jakimkolwiek wywołaniem `ingest`.
- Przebieg `check`: `ingest.verify_inputs` → `ingest.load_layers` → (miejsce na pipeline, na razie nic) → ponownie `ingest.verify_inputs` (AC-01) → wypisz liczności. `InputIntegrityError` w dowolnym kroku → komunikat po polsku na stderr z nazwą pliku, kod 1, bez raportu. Inny wyjątek → kod 3.
- **Ważne dla testów:** w `cli.py` wywołuj `ingest.verify_inputs(...)` i `ingest.load_layers(...)` przez moduł (`from map_qa import ingest`), nie przez `from map_qa.ingest import ...` — testy podmieniają je `monkeypatch.setattr(ingest, ...)`.
- Na stdout po polsku, np. `Drogi OSM: 99768`, `Segmenty Overture: 85405`, `Zdjęcia: 561`, `Znaki ograniczeń (traffic_signs): 1730`.
- Na Windows stdout ma kodowanie cp1250 — na początku `main` zrób `sys.stdout.reconfigure(errors="replace")` i to samo dla stderr (bez zmiany kodowania).
